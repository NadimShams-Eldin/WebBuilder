# قطمة (Qitma) - WebBuilder

محرّر مواقع ويب بصناديق البناء الأولية (Lego blocks). المستخدم يركّب المواقع من
عناصر أولية بحرية Flex/Grid تمامًا، مع لوحة خصائص وحركات، ثم يصدّر موقعًا
HTML/CSS/JS نظيفًا. لا قوالب جاهزة.

## الوثائق

- مواصفة التصميم: `docs/specs/2026-10-01-qitma-webbuilder-design.md`
- خطة مراحل البناء: `docs/ROADMAP.md`
- القطع الأساسية: تخطيط + محتوى + تفاعل (بدون سلوكيات في v1)
- التقنية: React + Vite + TypeScript + Tailwind + Zustand

## التشغيل

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء نسخة الإنتاج
npm run build

# فحص الكود
npm run lint

# اختبارات الوحدة
npm test
```

### المرحلة 0 - المنجز

مشروع Vite (React 19 + TypeScript) مع Tailwind v4 ودعم RTL، وZustand،
وoxlint وPrettier، وهيكل مجلدات المحرّر، وواجهة هيكلية ثلاثية المناطق
(القطع يمينًا، الكانفا وسطًا، الخصائص يسارًا).

### المرحلة 1 - المنجز

أنواع `Project` / `Page` / `Node` / `NodeStyle` / `NodeAnimation`،
و`createNode(type)` بالقيم الافتراضية، وقائمة بيضاء لخصائص CSS المصنّفة،
و`renderHtml` / `renderCss` كمصدر واحد للحقيقة، مع اختبارات وحدة عبر Vitest.

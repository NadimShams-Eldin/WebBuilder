# قطمة (Qitma) - WebBuilder

محرّر مواقع ويب بصناديق البناء الأولية (Lego blocks). المستخدم يركّب المواقع من
عناصر أولية بحرية Flex/Grid تمامًا، مع لوحة خصائص وحركات، ثم يصدّر موقعًا
HTML/CSS/JS نظيفًا. لا قوالب جاهزة.

## الوثائق

- مواصفة التصميم: `docs/specs/2026-10-01-qitma-webbuilder-design.md`
- خطة مراحل البناء: `docs/ROADMAP.md`
- خطة تطوير الواجهة (UI): `docs/UI_REDESIGN.md`
- سجل المناقشات والقرارات: `docs/DISCUSSIONS.md`
- القطع الأساسية: تخطيط + محتوى + تفاعل (بدون سلوكيات في v1)
- التقنية: React + Vite + TypeScript + Tailwind + Zustand

## التشغيل

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء نسخة الإنتاج
npm run build

# فحص الكود
npm run lint

# اختبارات الوحدة
npm test
```

### النموذج التجريبي (Demo model)

- رابط مباشر: `/?demo=1` — يفتح نموذجًا كاملًا (شريط علوي، بطل، مزايا، أرقام،
  نموذج، تذييل، وصفحة أصول) في جلسة معزولة تمامًا.
- في وضع النموذج لا تُكتب التعديلات فوق مشروعك المحفوظ (`qitma-project`)؛
  شارة «نموذج تجريبي» في شريط القوائم تتيح الخروج إلى مشروعك.
- الملف القابل للاستيراد: `public/demo/qitma-demo.json`، أو من
  «ملف ← تحميل ملف النموذج» داخل المحرّر.

### المرحلة 0 - المنجز

مشروع Vite (React 19 + TypeScript) مع Tailwind v4 ودعم RTL، وZustand،
وoxlint وPrettier، وهيكل مجلدات المحرّر، وواجهة هيكلية ثلاثية المناطق
(القطع يمينًا، الكانفا وسطًا، الخصائص يسارًا).

### المرحلة 1 - المنجز

أنواع `Project` / `Page` / `Node` / `NodeStyle` / `NodeAnimation`،
و`createNode(type)` بالقيم الافتراضية، وقائمة بيضاء لخصائص CSS المصنّفة،
و`renderHtml` / `renderCss` كمصدر واحد للحقيقة، مع اختبارات وحدة.

### المرحلة 2 - المنجز

كانفا داخل `iframe` معزول تُحقن فيه مخرجات المولّد عبر `srcdoc`، مع طبقة
علوية للتحديد لاحقًا، وقياس ارتفاع الإطار وتمركزه، وشجرة تجريبية تظهر
كقالب منسّق. الحالة في Zustand وتعيد البناء عند تغيّر المشروع.

### المرحلة 3 - المنجز

سجل القطع في `src/blocks/registry.ts`، ولوحة يمينية بثلاث مجموعات.
النقر يضيف الأصل إلى الحاوية المحددة (أو الجذر)، ويمنع إدخال الأبناء
داخل عنصر ورقة. الإضافة تظهر فورًا في الكانفا.

### المرحلة 4 - المنجز

نقر الكانفا يحدّد العنصر عبر `postMessage`، وإطار أزرق يبرزه فوق الـ iframe.
تبويب Outline يعرض شجرة طبقات قابلة للطي، والتحديد متزامن بين الشجرة والكانفا.

### المرحلة 5 - المنجز

لوحة خصائص بتبويبي المحتوى والأنماط. تعديل النص أو اللون يحدّث المخزن
والمعاينة والمولّد فورًا.

### المرحلة 6 - المنجز

سحب من لوحة القطع إلى الكانفا عبر dnd-kit، مع مؤشر قبل/بعد/داخل يدعم
RTL والصف الأفقي. إعادة ترتيب شجرة الطبقات تخضع لقيود الحاوية/الورقة.

### المرحلة 7 - المنجز

سجل لقطات للمشروع والتحديد (عمق 50). الإضافة والنقل والتعديل تدخل التاريخ،
وتجميعات تعديل الحقول المتتالية تُدمج. الأزرار وCtrl+Z / Ctrl+Y / Ctrl+Shift+Z
تعيد الحالة بدقة.

### المرحلة 8 - المنجز

أزرار حاسوب/لوحي/هاتف تضبط عرض الـ iframe (1280/768/390)، مع تكبير من 50%
إلى 150%. التفضيل يُحفظ في localStorage ويُستعاد عند فتح المحرّر.

### المرحلة 9 - المنجز

تبويب حركة في لوحة الخصائص (مشغّل/تأثير/مدة/تأخير/منحنى). المولّد يصدر CSS
للحركة وJS لـ scroll عبر IntersectionObserver في الكانفا والتصدير معًا.

### المرحلة 10 - المنجز

إدارة `pages[]` من الرأس: إضافة/حذف/إعادة تسمية ومسار. الكانفا تعرض الصفحة
النشطة، ورابط `link` يرتبط بصفحة داخلية. التصدير يولّد ملف HTML لكل صفحة
والتنقّل بينها يعمل في المعاينة.

### المرحلة 11 - المنجز

تصدير واستيراد ملف JSON مع التحقق من الشجرة، وحفظ تلقائي في localStorage.
الصور تُرفع كأصول داخل المشروع ويُختار منها في خصائص الصورة/الفيديو.

### المرحلة 12 - المنجز

زر «تصدير ويب» ينزّل حزمة zip فيها `index.html` وملف لكل صفحة، و`styles.css`
و`script.js` عند وجود حركة تمرير، وصور المشروع داخل `assets/`. الروابط الداخلية
تشير إلى ملفات الصفحات، والموقع المستخرج يطابق الكانفا.

### المرحلة 13 - المنجز

تبويب «المستخرج» في اللوحة اليمنى يجمع الحقول النصية من شجرة الصفحة
(عناوين، فقرات، أزرار، روابط، قوائم، بدائل الصور، حقول الإدخال). تعديل حقل
يحدّث العنصر فورًا ويحدّده في الكانفا ولوحة الخصائص.

### المرحلة 14 - المنجز

تبويب «معاينة حية» يخفي لوحات القطع والخصائص وإطار التحديد. الصفحة تُعرض
كما يراها الزائر، والروابط الداخلية تنتقل بين الصفحات. Escape يعيد لوحة التركيب.

### أدلة الكانفا - المنجز

تمرير العنصر يرسم إطارًا أخضر، والتحديد إطارًا أزرق مع قائمة عائمة للتكرار والحذف
(Ctrl+D). الحاويات الفارغة تظهر بحدود متقطعة، والشبكة المحددة تعرض خطوط الأعمدة
والصفوف عند توفر مقاسات بالبكسل. أدلة التحرير تُخفى في وضع المعاينة.
